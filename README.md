# BrowserTradingAgents

> **Research completed / archived (2026-10-01).** See [FINAL_REPORT.md](FINAL_REPORT.md) for the results,
> limitations and the conditions for reopening.

A TradingAgents-style multi-agent application that runs in the browser (Chrome Prompt API through AkariSP), built to
dogfood AkariSP and to measure how far a browser LLM goes on a grounded, portfolio-aware workload. Paper trading only;
no investment advice.
