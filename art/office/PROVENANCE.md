# Office art provenance (Feature 011)

named in *source*, drawn in this repository for BrowserTradingAgents. No third-party art is used. The
repository has no licence file; choosing a licence for the repository or this art is a maintainer decision
(spec FR-005), so the status below records the situation as it is.
