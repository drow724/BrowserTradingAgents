## 평가 (LLM 심사, blind)

**심사자**
- Claude Opus 서브에이전트가 심사한다. 시나리오 원본(`must_include`, `must_not` 포함)과 후보 5개를 받는다. 후보 5개는 A, B r1, B r2, B r3, C다.
- 후보 라벨은 시나리오마다 고정 seed로 섞은 X1~X5다. 심사자는 어떤 라벨이 어느 조건인지 모른다.

**후보별 채점 항목**

| 항목 | 척도 | 기준 |
|---|---|---|
| `intent` | 0/1/2 | `must_include`를 전부 정확히 전달하면 2, 일부만 전달하면 1, 전달하지 못하면 0 |
| `hallucination` | bool | 의도나 대화에 없는 사실·날짜·약속·이유를 추가했거나 `must_not`을 위반했으면 true |
| `register` | 0/1/2 | 관계와 대화 말투에 맞는 정도 |
| `natural` | 1~5 | 자연스러운 한국어 채팅 문장인 정도 |
| **`usable`** | bool | 그대로 보내거나 아주 사소한 수정(몇 글자)만 하면 보낼 수 있는가 |

**심사 일관성 검증**
- test 중 12개 시나리오(20%)를 무작위로 고른다.
- 라벨을 다시 섞어 별도 Opus 심사자가 재심사한다.
- `usable`의 일치율과 Cohen's kappa를 보고한다.

**자동 검증 (심사자와 독립)**
- `must_include` 중 URL, 이메일, 경로, 숫자가 들어간 항목이 대상이다.
- 해당 문자열이 초안에 그대로 들어 있는지 확인하고, 그 비율을 보고한다.
