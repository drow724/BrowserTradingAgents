## 실행

- 같은 test set으로 모델을 **3회 독립 실행**한다: r1, r2, r3.
- 실행마다 base session을 새로 `create`한다.
- 분류기는 결정론적이다. 따라서 세 실행 사이의 차이는 모델 비결정성에서만 생긴다.

## 판정 기준

**각 실행마다** 아래 기준을 모두 충족해야 한다.

| 항목 | 기준 |
|---|---|
| 전체 accuracy | 90% 이상 |
| CLARIFY recall | 80% 이상 |
| 과잉 되묻기 | 5% 이하 |
| p95 (모델 호출 item 기준) | 1초 이하 |
| invalid | 1% 미만 |
| structured | 99% 이상 |

결과는 다음 셋 중 하나로 판정한다.

- **PASS**: 3회 모두 모든 기준을 충족한다.
- **PARTIAL**: 1회 또는 2회만 충족한다. 경계선으로 기록한다.
- **FAIL**: 3회 모두 하나 이상의 기준을 미충족한다.
